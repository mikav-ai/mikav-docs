# Roadmap

> The path ahead for Mikav Docs — what we're building, what's next, and where we're headed.

## Vision

Make Mikav's documentation the most accessible, comprehensive, and community-driven resource for building on Kerala's open AI ecosystem.

---

## 🟢 Completed

- [x] Initial Docusaurus setup
- [x] AWS Amplify deployment pipeline
- [x] Custom domain (docs.mikav.in)
- [x] Community files (Contributing, Code of Conduct, Security)
- [x] Base documentation structure

## 🟡 In Progress

- [ ] Core documentation for Mikav AI model
- [ ] API reference documentation
- [ ] Getting started guides
- [ ] Malayalam language support (i18n)

## 🔵 Planned (Next)

- [ ] Interactive API playground
- [ ] SDK documentation (Python, JavaScript, Go)
- [ ] Use case examples and tutorials
- [ ] Model fine-tuning guides
- [ ] Plugin/extension documentation
- [ ] Search integration (Algolia / local search)
- [ ] Community showcase page

## 🟣 Future

- [ ] Video tutorials and walkthroughs
- [ ] AI-powered doc search (powered by Mikav itself)
- [ ] Multi-language support (Tamil, Kannada, Hindi)
- [ ] Developer certification guides
- [ ] Offline documentation (PWA)
- [ ] Community-contributed recipes and patterns
- [ ] Integration guides (LangChain, LlamaIndex, etc.)

---

## How to Influence the Roadmap

We welcome input from the community! Here's how you can shape what comes next:

1. **Vote on issues** — React with 👍 on issues you care about
2. **Open a feature request** — Describe the documentation you'd like to see
3. **Contribute directly** — PRs for roadmap items are always welcome
4. **Join [discussions](https://github.com/orgs/mikav-ai/discussions)** — Share your use case and what docs would help most

---

_This roadmap is a living document. Priorities may shift based on community needs and project milestones._
