# Models Overview

Mikav provides a family of open AI models optimized for Malayalam language understanding and generation.

## Available Models

| Model | Parameters | Context | Best For |
|-------|-----------|---------|----------|
| mikav-1 | — | 8K tokens | General purpose chat and text generation |
| mikav-1-mini | — | 4K tokens | Fast responses, lightweight tasks |
| mikav-1-code | — | 16K tokens | Code generation with Malayalam support |

## Model Capabilities

### mikav-1

Our flagship model. Best for:

- Natural conversation in Malayalam and English
- Content writing and editing
- Translation with cultural context
- Question answering and summarization

### mikav-1-mini

A smaller, faster model for:

- Quick responses and simple tasks
- Low-latency applications
- Edge deployment scenarios
- Cost-sensitive use cases

### mikav-1-code

Specialized for code tasks:

- Code generation in multiple languages
- Code explanation with Malayalam comments
- Bug detection and fixing
- Documentation generation

## Choosing a Model

- **Need quality?** Use `mikav-1`
- **Need speed?** Use `mikav-1-mini`
- **Need code?** Use `mikav-1-code`

## Open Weights

All Mikav models are available as open weights under permissive licenses. You can:

- Download and run locally
- Fine-tune for your specific use case
- Deploy on your own infrastructure
- Inspect and audit the model

See [How to Use Models](./how-to-use.md) for integration guides.
