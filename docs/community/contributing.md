# Contributing

We welcome contributions from everyone. Mikav is a community-driven project, and your help makes it better for all Malayalam speakers.

## Ways to Contribute

- **Documentation** — Fix typos, improve explanations, add examples
- **Code** — Bug fixes, new features, performance improvements
- **Data** — Contribute to our open datasets
- **Translation** — Help translate docs to Malayalam and other languages
- **Feedback** — Report bugs, suggest features, share your use cases

## Getting Started

1. Fork the repository on GitHub
2. Clone your fork locally
3. Create a feature branch
4. Make your changes
5. Submit a pull request

## Development Setup

```bash
git clone https://github.com/mikav-ai/mikav-docs.git
cd mikav-docs
npm install
npm start
```

## Guidelines

- Follow existing code style and conventions
- Write clear commit messages using [Conventional Commits](https://www.conventionalcommits.org/)
- Add tests for new features where applicable
- Update documentation when changing behavior
- Be respectful and constructive in discussions

## Code of Conduct

All contributors must follow our [Code of Conduct](https://github.com/mikav-ai/mikav-docs/blob/main/CODE_OF_CONDUCT.md).

## Need Help?

- Open a [discussion](https://github.com/orgs/mikav-ai/discussions) for questions
- Check existing [issues](https://github.com/mikav-ai/mikav-docs/issues) before creating new ones
- Look for issues labeled `good first issue` for beginner-friendly tasks
