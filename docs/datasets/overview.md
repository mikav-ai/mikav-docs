# Datasets Overview

Mikav provides open datasets to support research and development in Malayalam NLP and AI.

## Available Datasets

| Dataset | Description | Size | License |
|---------|-------------|------|---------|
| Mikav-Text-1 | General Malayalam text corpus | — | Apache 2.0 |
| Mikav-Conversations | Conversational Malayalam data | — | Apache 2.0 |
| Mikav-Code | Malayalam-annotated code samples | — | Apache 2.0 |

## Design Principles

Our datasets are built with these principles:

- **Quality over quantity** — Curated and cleaned data
- **Cultural representation** — Diverse Malayalam content from across Kerala
- **Ethical sourcing** — Proper attribution and consent
- **Open access** — Available for research and commercial use

## Data Sources

Our datasets are compiled from:

- Publicly available Malayalam literature and texts
- Community-contributed content
- Synthetic data generated with human validation
- Licensed content with proper attribution

## Usage Policy

- Datasets are provided under Apache 2.0 unless otherwise noted
- Attribution is required when using datasets in published work
- Datasets must not be used to generate harmful or misleading content

## Getting Access

Datasets are available through:

1. **Direct download** — From our data portal
2. **Hugging Face** — Available on our Hugging Face organization
3. **API** — Programmatic access via the Mikav SDK

See [How to Use Datasets](./how-to-use.md) for detailed instructions.
