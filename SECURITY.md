# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ Yes             |

## Reporting a Vulnerability

We take security seriously at Mikav. If you discover a security vulnerability, please report it responsibly.

### How to Report

1. **Do NOT** open a public GitHub issue for security vulnerabilities.
2. Email us at: **security@mikav.in**

3. Include the following details:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment** within 48 hours of your report
- **Assessment** within 5 business days
- **Resolution timeline** communicated within 10 business days
- **Credit** given to reporters (unless anonymity is preferred)

### Scope

This security policy applies to:

- The Mikav documentation site (this repository)
- Any API keys, secrets, or credentials that may be exposed
- Dependencies with known vulnerabilities

### Best Practices for Contributors

- Never commit secrets, API keys, or credentials
- Keep dependencies updated
- Use environment variables for sensitive configuration
- Follow the principle of least privilege

## Disclosure Policy

We follow a coordinated disclosure process. Please allow us reasonable time to address vulnerabilities before public disclosure.

Thank you for helping keep Mikav and our community safe. 🙏
